# 🪽 위시 RP Manager

### 장기 RP용 컨텍스트 관리 · 날짜로그 호출 · 캐릭터 설정 · OOC 주입

현재상태와 날짜별 로그, 캐릭터 설정을 관리하고  
**지금 필요한 문맥만 골라 다음 RP에 이어주는 Tampermonkey 사용자 스크립트입니다.**

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🧭 **현재상태** | 다음 RP에 필요한 최신 상태·관계·정보격차·미해결 후크 관리 |
| 🗓️ **날짜로그** | 긴 로그를 날짜별로 분리해 저장하고 필요한 날짜만 호출 |
| 🔎 **관련로그 호출** | 현재 RP와 겹치는 사건명·장소·물건·희귀 키워드 기반으로 과거 로그 탐색 |
| 👤 **캐릭터 설정** | 설정집 저장·불러오기 및 최근 RP의 등장 캐릭터 자동 감지 |
| 📌 **주입 제어** | 직접 선택 / 항상 호출 / 자동 제외 / 유지턴 설정 |
| ⚙️ **기타/OOC** | 출력 규칙·사칭방지·관계 진행 지침 등 여러 턴 유지 |
| 📋 **내장 지침** | 현재상태·날짜로그 갱신용 프롬프트 복사 및 수정 저장 |

## 🧠 기본 구조

~~~text
🧭 현재상태
     +
🗓️ 최신 날짜로그
     +
🗓️ 관련 과거로그
     +
👤 등장 캐릭터 설정
     +
⚙️ 필요한 OOC
        ↓
45,000자 안에서 조립
        ↓
다음 RP에 필요한 컨텍스트 주입
~~~

사용자의 **USER 메시지는 수정하지 않습니다.**

---

## 🗓️ 날짜로그

전체 날짜로그를 한 칸에 붙여넣으면 내부에서 날짜 단위로 나눠 관리합니다.

~~~text
2026년
 └─ 3월
     ├─ 3/15
     ├─ 3/16
     ├─ 3/17
     └─ ...
~~~

실제 주입에는 전체 로그를 무조건 넣지 않고,

- 📌 항상 호출
- ☑ 직접 선택
- 최신 로그
- 관련 과거 로그

를 조합해 필요한 블록만 사용합니다.

---

## 🔎 관련 과거 로그 호출

관련로그 검색은 **외부 AI API를 사용하지 않습니다.**

브라우저 안에서 최근 RP와 날짜로그를 비교해 다음 요소에 가중치를 줍니다.

~~~text
사건명 / 장소 / 물건 / 특이·희귀 키워드
                     ↓ 강하게

캐릭터 이름
                     ↓ 보조
~~~

따라서 API 키나 별도 비용은 필요하지 않습니다.

> 의미를 완전히 이해하는 임베딩/RAG 검색은 아니므로  
> 표현이 완전히 달라진 사건은 놓칠 수 있습니다.  
> 이 경우 직접 선택 또는 📌 항상 호출로 보완할 수 있습니다.

---

## 👤 캐릭터 설정

캐릭터 설정집을 저장해 여러 채팅방에서 재사용할 수 있습니다.

- 등장 캐릭터 자동 감지
- 추가 별칭 등록
- 📌 자동 고정
- 이름감지 제외
- 다시 등장하면 유지턴 리셋

각 채팅방의 체크 상태와 남은 유지턴은 별도로 관리됩니다.

---

## ⚙️ 기타 / OOC

여러 턴 동안 반복해서 넣어야 하는 지침을 따로 보관할 수 있습니다.

예:

- 출력 형식
- 사칭방지
- 특정 장면용 OOC
- 관계 진행 지침
- 성인 RP 진행 규칙

`직접 해제`로 설정하면 사용자가 끌 때까지 계속 유지됩니다.

## ⚠️ 참고

- RP Manager의 최대 주입량은 현재 **45,000자**로 설정되어 있습니다.
- 이는 확인된 서버 절대한도가 아니라 실사용을 위한 안전선입니다.
- 관련로그 자동 검색은 AI 의미추론이 아닌 로컬 키워드 점수 방식입니다.
- 자동요약용 외부 LLM API는 사용하지 않습니다.
- 로그 원본은 주입량을 초과해도 자동 삭제되지 않습니다.
- USER 메시지는 수정하지 않습니다.
